# pagina-de-gracias

Skill gratis para Claude Code, con el método que uso en **Flowboost Marketing**.

**Qué hace:** La página de gracias que hace que el lead espere tu llamada: quién llama, cuándo, desde qué número y de qué se habla

**Qué te deja:** `gracias.html`

## Instalación

```bash
git clone https://github.com/diegogwork1-alt/pagina-de-gracias.git
mkdir -p ~/.claude/skills
cp -r pagina-de-gracias/pagina-de-gracias ~/.claude/skills/
```

Si solo la quieres en un proyecto, cópiala en la carpeta `.claude/skills/` de ese proyecto.

## Cómo se usa

Abre Claude Code en la carpeta de tu proyecto y pídelo con tus palabras, por ejemplo: «Hazme la página de gracias»
